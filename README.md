## 🚀 Key Projects

* **[Chat Messenger](https://github.com/RadoslawSmoronski/communicator)** - 1-on-1 chat platform built in collaboration with a partner, where I was responsible for frontend implementation. Built with React.js using SignalR for real-time communication.
* **[2D Space Shooted](https://github.com/Aneiv/2d-shooter-project)** - 2 people project. 2D space shooter game developed in Unity for Android. Gameplay revolves around clearing enemy waves with increasing difficulty. Supports cooperative multiplayer via the Mirror library. Features a lobby system for creating and joining rooms over LAN, alongside procedural map generation.
* **[Awerly](https://github.com/cherries-kosciuszkon/kosciuszkon)** - Team project developed during a hackathon using React.js and ASP.NET Core. An educational platform for cyber threat awareness, integrating AI models via the Gemini API.
